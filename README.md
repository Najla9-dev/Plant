# Planto 🌱

Planto is an iOS app that helps you take care of your plants. Set a reminder for each plant and track which ones you have watered today.

## Main Features

- Add a plant reminder with name, room, light, watering days and water amount
- Edit or delete a reminder (tap a plant, or swipe to delete)
- Mark plants as watered and see your progress with a progress bar
- Dedicated screens for first launch, no reminders, and "All Done"
- Local notification reminders
